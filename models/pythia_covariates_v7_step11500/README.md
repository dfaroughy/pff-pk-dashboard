# Pythia-Covariates — step 11,500 local preview

Latest readable checkpoint at the September 13 Amarel export: **11,500 / 120,000
optimizer steps**. This remains an early training snapshot, not a validated release.
The ongoing four-GPU training job is untouched.

`manifest.json` records the source run, stable export, expected bytes and SHA-256.
The checkpoint stays in `pff_pk/artifacts/checkpoints/`, outside the dashboard
repository. Nothing in this preview authorizes publishing the weights or service.

The model retains semantic/generic covariates, per-target covariate conditioning,
and optional LLOQ/CENS support. Missing covariates and absent assay floors remain
masked. Covariates are supplied by the user/context, not generated by this model.

Select **Pythia-Covariates** in the local dashboard. The step-5,000 checkpoint
remains available as a fallback using `PFF_COVARIATES_CONFIG` and
`PFF_COVARIATES_CHECKPOINT` environment overrides.
